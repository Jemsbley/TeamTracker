Generator's University Team Tracking System

About this site

Last updated 15 September 2026

The Generator's University Team Tracking System is a match-tracking and analytics tool for competitive Valorant teams. A team records its matches here round by round, and the site turns that history into the numbers the team uses to prepare for the next one.

This is a private tool, not a public database. Accounts are invite-only and each roster's data is visible only to the people invited to that roster. There is no public match history, leaderboard, or player directory to browse, and nothing here is scraped from or resold to anyone else.

What it does

Round-by-round match records

A match is recorded as a series of maps, and each map as an ordered list of rounds. Every round captures who won it, how, and what both teams spent, which is what makes the economy and side-split analysis below possible.

Team, map, and agent analytics

Recorded matches roll up into win rates and round differentials by map, split by attack and defense, and by the agent composition that was played. The intent is to answer questions like which maps are actually trending up and whether a given composition holds up on defense.

Player breakdowns

Per-player performance can be filtered by map, agent, role, and date range, so a player's numbers on a specific agent on a specific map are separable from their overall averages.

Map veto planning

Pick and ban sequences can be built and replayed against a particular opponent, using that opponent's recorded map tendencies.

VOD review

Match videos and written review notes attach to the series they belong to, so review notes stay next to the match data instead of in a separate document.

Opponent scouting

Scouting reports on upcoming opponents live alongside their observed map and agent tendencies, so preparation for a specific match is in one place.

How it is built

The site is a React single-page application talking to a Node and Express API backed by a PostgreSQL database. Sign-in is handled by Google Sign-In; the site never sees or stores a password. See the Privacy Policy for exactly what is stored.

Getting access

Access is granted by invitation from a roster owner. If you are on a team that uses this tool, ask your roster owner for an invite link. If you already have an account, you can sign in below.
